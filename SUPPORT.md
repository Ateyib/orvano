# Getting help

- **Questions** ("how do I…", "is this a bug or me?"): ask in [Discussions Q&A](https://github.com/orvanohq/orvano/discussions/categories/q-a).
- **Bugs and feature requests:** open an issue with the [issue forms](https://github.com/orvanohq/orvano/issues/new/choose). For an SDK, use that SDK's repo under [`orvanohq`](https://github.com/orvanohq).
- **Security vulnerabilities:** never in public. Follow [SECURITY.md](SECURITY.md).

Orvano is a community project with no paid support. Maintainers and contributors answer when they can, so a clear question with your version, install method, and what you tried gets the fastest answer.
