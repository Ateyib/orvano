# Orvano

Orvano is an open source, self hostable backend as a service: auth, databases, storage, realtime, functions, sites, and messaging, with a web console and SDKs for Flutter, Dart, JavaScript, TypeScript, Next.js, and .NET. It runs as one server image with PostgreSQL beside it. It's in early development and not ready for production yet.

| Repo                                                        | What it is                                     |
| ----------------------------------------------------------- | ---------------------------------------------- |
| [orvano](https://github.com/orvanohq/orvano)                | The server, console, API contract, and docs    |
| [sdk-flutter](https://github.com/orvanohq/sdk-flutter)      | `orvano_flutter`, the Flutter client SDK       |
| [sdk-dart](https://github.com/orvanohq/sdk-dart)            | `orvano_server`, the Dart server SDK           |
| [sdk-js](https://github.com/orvanohq/sdk-js)                | `@orvano/client`, the JavaScript client SDK    |
| [sdk-js-server](https://github.com/orvanohq/sdk-js-server)  | `@orvano/server`, the JavaScript server SDK    |
| [sdk-nextjs](https://github.com/orvanohq/sdk-nextjs)        | `@orvano/nextjs`, the Next.js SDK              |
| [sdk-dotnet](https://github.com/orvanohq/sdk-dotnet)        | `Orvano.Server`, the .NET server SDK           |
