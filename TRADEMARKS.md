# Trademarks

Orvano's code is licensed under the [Apache License 2.0](LICENSE). That license covers the code. It doesn't grant rights to the name "Orvano" or its logo (Apache 2.0 section 6).

## What's fine

- Running Orvano, unmodified or with your own configuration, and calling it Orvano.
- Saying your product **works with Orvano**, **is built on Orvano**, or **is a hosted Orvano** (when it runs Orvano unmodified).
- Naming Orvano when you write or talk about it.

## What needs a different name

- A **modified fork** of Orvano must use a different name and logo.
- A **hosted service built on a modified Orvano** must use a different name and logo.

You can still say a fork is "based on Orvano", as long as nobody could mistake it for the official project.
